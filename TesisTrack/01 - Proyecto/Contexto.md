# Contexto

TesisTrack es una plataforma web orientada a **centralizar y facilitar el seguimiento de proyectos de tesis durante el proceso de asesoría**.

La idea nace porque durante la elaboración de una tesis se genera mucha información:

- Reuniones de asesoría
- Acuerdos
- Tareas pendientes
- Fechas de entrega
- Hitos
- Entregas de documentos
- Versiones de documentos
- Observaciones del asesor
- Correcciones realizadas
- Historial del proceso

Actualmente esta información puede encontrarse distribuida entre WhatsApp, correo electrónico, documentos, reuniones y otros medios.

> [!info] Diagnóstico
> El problema no es necesariamente que la información no exista, sino que **está dispersa** y resulta difícil realizar un seguimiento claro del proyecto.

TesisTrack busca concentrar esta información en un único espacio.
