# Objetivos

## Objetivo general

Desarrollar una plataforma web para centralizar y facilitar el seguimiento de las asesorías de proyectos de tesis, permitiendo registrar y consultar de manera organizada sus hitos, reuniones, entregas, observaciones y tareas pendientes.

## Objetivos específicos

- [ ] Registrar proyectos de tesis y vincularlos con sus estudiantes y asesores
- [ ] Definir y gestionar los principales hitos del proyecto
- [ ] Registrar reuniones de asesoría
- [ ] Registrar los acuerdos establecidos durante las reuniones
- [ ] Registrar tareas pendientes derivadas de las asesorías
- [ ] Registrar entregas de documentos asociadas a los hitos
- [ ] Permitir que el asesor registre observaciones sobre las entregas
- [ ] Mantener un historial organizado del proceso de asesoría
- [ ] Mostrar tareas pendientes y próximas fechas importantes
- [ ] Visualizar el estado general del proyecto
