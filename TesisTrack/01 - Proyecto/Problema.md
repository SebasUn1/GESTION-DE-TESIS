# Problema que queremos resolver

Durante el desarrollo de una tesis, el estudiante y el asesor necesitan realizar un seguimiento constante del avance.

Sin una herramienta centralizada pueden aparecer problemas como:

- No recordar qué se acordó en una asesoría
- Perder de vista tareas pendientes
- No saber qué observaciones ya fueron corregidas
- Confundir versiones de documentos
- No identificar claramente cuál es la siguiente actividad
- Perder tiempo buscando información en diferentes medios
- Tener dificultad para reconstruir el historial de asesorías
- No tener una visión rápida del estado actual de la tesis

> [!important] Problema central
> La dificultad para organizar, centralizar y dar seguimiento a la información generada durante las asesorías de un proyecto de tesis.
